# AGORA — Brand Identity Guidelines (Concept 1: Architectural Monogram)

## 1. Brand Philosophy
Agora is a visual-noise-free, text-only platform built for deep discourse, long-form essays, and reasoned debate. The visual identity reflects structural stability, intellect, and clarity.

## 2. Logo System Components
Concept 1 utilizes structural geometry—drawing inspiration from ancient debate forums (agoras) transformed into modern, sharp typography and a standalone monolithic "A" monogram.

### Files Included:
- `agora-wordmark-light.svg`: Primary wordmark for light backgrounds.
- `agora-wordmark-dark.svg`: Primary wordmark for dark mode / dark backgrounds.
- `agora-monogram-512.svg`: App Icon & High-resolution standalone symbol (512x512).
- `favicon-32x32.svg`: Optimized micro-scale favicon for browser tabs (32x32).
- `favicon-64x64.svg`: Optimized small-scale icon (64x64).

## 3. Typography & Spacing Guidelines
- **Wordmark Style:** High-contrast extended sans/serif geometric hybrid (Monument Extended / Tiempos structure).
- **Tracking / Letter-spacing:** Wide tracking (+150 to +200 em) when set in text contexts to maintain structural posture.
- **Minimum Clear Space:** 50% of the height of the letter 'A' around all edges of the mark.

## 4. Color Palette
- **Primary Ink:** `#0D0D0D` (Pure obsidian black)
- **Primary Paper:** `#FBFBF9` (Off-white / Warm parchment neutral)
- **Accent (Optional):** `#C84B31` (Terracotta / Deep Rust red for active indicators)

## 5. Usage Rules
- **Do not** apply drop shadows, gradients, or non-neutral colors directly to the mark.
- **Do not** distort, stretch, or alter the geometric proportions of the inner "A" aperture.
- The monogram MUST be used as the app icon and favicon across iOS, Android, and Web platforms.
